# Alp-1

Alp-1 est un projet de **stratégie de trading quantitatif**. L'objectif est de concevoir, tester et exécuter des stratégies de trading basées sur des modèles statistiques et algorithmiques plutôt que sur des décisions discrétionnaires.

## Objectif du projet

Le projet vise à :

- Développer des signaux de trading à partir de données de marché (prix, volumes, etc.)
- Backtester ces stratégies sur des données historiques pour évaluer leur performance
- Automatiser l'exécution des ordres selon des règles définies à l'avance
- Gérer le risque (dimensionnement des positions, stop-loss, exposition) de manière systématique

## État actuel

Le projet en est à ses débuts. Le point d'entrée se trouve dans `main.py`.

## Démarrage

```bash
python main.py
```
